# OCI-SentinelMesh

Autonomous cloud health and compliance monitoring agent for Oracle Cloud Infrastructure.

OCI-SentinelMesh is designed to monitor OCI resources, detect anomalies, map events to compliance rules, and provide explainable alerts through an AI-assisted backend and dashboard.

## Status

Project setup in progress.

## Planned Stack

- Oracle Cloud Infrastructure
- OCI Python SDK
- Oracle Autonomous Database
- FastAPI
- React + TypeScript
- Kubernetes / Helm
- AI agent workflow
